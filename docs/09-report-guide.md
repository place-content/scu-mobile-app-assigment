## 필요한 스크린샷
| # | 화면 | 보여줄 것 |
|---|---|---|
| 1 | 목록 (빈 상태) | "할 일이 없습니다" |
| 2 | 목록 (데이터 있음) | 세 가지 상태가 섞여 있는 목록, 필터 개수, "마감" 라벨 |
| 3 | 목록 (필터 "진행 중") | 필터링 결과 |
| 4 | 목록 (선택 중) | 체크된 항목 + `선택 해제` / `선택 삭제 (n)` |
| 5 | 삭제 확인 창 | 삭제 글자 색 |
| 6 | 길게 누르기 메뉴 / 상태 변경 창 | `상태 변경 / 수정 / 삭제`, 3단계 선택 |
| 7 | 추가 화면 + 달력 | 오늘 이전 날짜가 회색 |
| 8 | 편집 화면 | 기존 값이 채워진 상태, 상태 Spinner |
| 9 | Toast | "저장했습니다" 등 |

## 알려진 한계 (향후 개선 방향)
| 한계 | 설명 | 개선 방법 |
|---|---|---|
| 선택 중 항목 탭 | 체크박스 선택 중에 항목 본문을 탭하면 편집 화면으로 이동 (보통 앱은 선택이 토글됨) | 선택 중에는 항목 탭 = 선택 토글 |
| 키보드 자동 표시 없음 | 추가 화면에 들어가도 제목 칸을 한 번 더 눌러야 함 | 화면 진입 시 제목 칸에 포커스 + 키보드 표시 |
| 입력 유실 | 추가/편집 중 뒤로가기를 누르면 확인 없이 입력이 사라짐 | 변경 사항이 있으면 "나갈까요?" 확인 |
| 새 항목 위치 | 목록을 내린 상태에서 추가하면 새 항목이 맨 위(화면 밖)에 생김 | 추가 후 목록 맨 위로 스크롤 |
| 정렬 | 추가 순서로만 정렬, 마감일 가까운 순 정렬 없음 | 정렬 옵션 추가 |
| 지난 마감 표시 | 기한이 지난 할 일을 따로 표시하지 않음 | 마감일이 지났으면 날짜 색 변경 |
| 다크 모드 | 같은 강조색을 써서 어두운 배경에서 체크박스·라디오가 덜 보일 수 있음 | `values-night/colors.xml`에 밝은 톤 지정 |
| DB 마이그레이션 | DB 구조를 바꾸면 기존 데이터 처리 코드가 없음 | Room Migration 작성 |
| 여러 기기 공유 | 교안 심화 F2.1~F2.3 미구현 | Firebase 등 원격 저장소 + 동기화 |
