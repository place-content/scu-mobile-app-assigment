## 2. 수동 테스트 체크리스트
에뮬레이터나 실제 기기에서 확인합니다. 보고서에 "테스트 및 검증" 표로 그대로 써도 됩니다.

### 조회 · 추가 · 저장 (F1.1 ~ F1.3)
- [ ] 첫 실행 시 "할 일이 등록되지 않았습니다"가 보인다
- [ ] 화면 제목 오른쪽에 `+ 추가`가 있다 (선택 중엔 그 자리가 선택 바로 바뀌고, 선택을 풀면 다시 보인다)
- [ ] `+ 추가` → 제목이 비어 있으면 저장 버튼이 흐리게(비활성) 보인다
- [ ] 비활성 저장 버튼을 누르면 제목 칸 밑줄이 빨갛게 바뀌고 "제목을 입력하세요"가 나온다
- [ ] 제목을 입력하면 저장 버튼이 활성화되고 빨간 표시가 사라진다
- [ ] 마감일 칸을 누르면 키보드 대신 달력이 뜨고, 고른 날짜가 `YYYY-MM-DD`로 채워진다
- [ ] 달력에서 오늘 이전 날짜는 선택할 수 없다
- [ ] 날짜가 있는 상태에서 다시 누르면 그 날짜가 선택된 채로 달력이 열린다
- [ ] 달력의 `지우기`를 누르면 마감일이 비워진다
- [ ] 저장하면 목록 맨 위에 나타나고 "저장했습니다" Toast
- [ ] 목록에 마감일이 `마감 2026-12-01`처럼 표시된다 (없으면 안 보임)
- [ ] 추가 화면에서 `<`이나 뒤로가기를 누르면 아무것도 추가되지 않는다
- [ ] 추가 화면에 들어가면 제목 칸에 커서가 있고 키보드가 바로 뜬다
- [ ] 제목·메모·마감일 중 하나라도 입력한 뒤 `<`·뒤로가기 → "저장하지 않은 내용이 있습니다. 나갈까요?" → `계속 작성`이면 입력 유지, `나가기`면 추가되지 않음
- [ ] 아무것도 입력하지 않았으면 확인 없이 바로 나간다
- [ ] 목록을 아래로 내린 상태에서 추가해도 맨 위로 스크롤되어 새 항목이 보인다
- [ ] 목록을 내려 둔 채 화면을 회전하거나 필터·상태를 바꾸면 보던 위치가 유지된다 (맨 위로 튀지 않음)
- [ ] 마감일이 지난 미완료 항목은 `마감 YYYY-MM-DD · 지남`이 경고색(`#B5473A`)으로 보이고, 완료하면 원래대로 돌아간다
- [ ] 앱을 완전히 종료했다가 다시 켜도 목록이 남아 있다

### 상태 변경 · 완료 표시 (F1.4, F1.6, 추가 기능)
- [ ] 할 일의 `시작 ▶` → 제목 앞에 `[진행 중]`, 버튼이 `완료 ▶`로 바뀐다
- [ ] `완료 ▶` → 제목 취소선 + 흐리게, 이동 버튼이 사라진다
- [ ] 길게 누르기 → `상태 변경` → 완료 항목을 할 일로 되돌릴 수 있다
- [ ] 필터 버튼의 개수가 상태 변경에 맞춰 바뀐다

### 수정 (F1.4)
- [ ] 항목을 누르면 편집 화면에 기존 제목·메모·마감일·상태가 채워져 있다
- [ ] 내용과 상태를 바꾸고 저장하면 목록에 반영되고 "수정했습니다" Toast
- [ ] 편집 화면에서 `<`이나 뒤로가기를 누르면 변경되지 않는다
- [ ] 편집 화면에서 아무것도 안 바꾸고 `<` → 바로 나감 / 무언가 바꾸고 `<` → "나갈까요?" 확인
- [ ] 바꾼 뒤 화면을 회전하고 `<`를 눌러도 "나갈까요?" 확인이 뜬다
- [ ] "나갈까요?" 창이 떠 있을 때 회전해도 창이 그대로 남고, `나가기`를 누르면 정상적으로 나간다
- [ ] 편집 화면을 열자마자 회전해도 기존 값이 채워진다
- [ ] 편집 중에 화면을 회전해도 입력 중인 내용이 유지된다

### 삭제 (F1.5, 추가 기능)
- [ ] 길게 누르기 → `삭제` → 확인 창에서 취소하면 그대로, 삭제하면 사라지고 "삭제했습니다" Toast
- [ ] 편집 화면의 `삭제`도 확인 후 삭제된다
- [ ] 확인 창의 `삭제` 글자와 삭제 버튼이 `#B5473A` 색이다
- [ ] 체크박스를 고르면 상단 헤더가 `n개 선택됨` · `선택 해제` · `삭제`로 바뀌고 n이 맞다 (칩과 목록 위치는 그대로)
- [ ] 상단 `삭제` → 확인 → 고른 항목만 사라지고 "n개 삭제했습니다" Toast
- [ ] `선택 해제`나 뒤로가기를 누르면 선택이 풀리고 상단이 `할 일 목록 [+ 추가]`로 돌아온다
- [ ] 선택한 상태에서 필터를 바꾸면 선택이 초기화된다
- [ ] 선택 중에는 항목 본문을 탭해도 편집 화면이 열리지 않고 선택이 토글된다 (선택이 0개가 되면 다시 탭 = 편집)

### 필터 (추가 기능)
- [ ] 필터 버튼을 누르면 해당 상태만 보이고, 괄호 안 개수가 맞다
- [ ] "진행 중" 필터에서 `완료 ▶`를 누르면 그 항목이 목록에서 빠진다
- [ ] 화면을 회전해도 선택한 필터와 목록이 유지된다
- [ ] 항목이 없는 필터를 고르면 "완료 항목이 없습니다"처럼 상태 이름이 보인다 (전체가 비면 "할 일이 등록되지 않았습니다")
