## 2. 수동 테스트 체크리스트
에뮬레이터나 실제 기기에서 확인합니다. 보고서에 "테스트 및 검증" 표로 그대로 써도 됩니다.

### 조회 · 추가 · 저장 (F1.1 ~ F1.3)
- [ ] 첫 실행 시 "할 일이 없습니다"가 보인다
- [ ] `+ 추가` → 제목 없이 저장하면 막히고 "제목을 입력하세요" Toast
- [ ] 마감일 칸을 누르면 키보드 대신 달력이 뜨고, 고른 날짜가 `YYYY-MM-DD`로 채워진다
- [ ] 달력에서 오늘 이전 날짜는 선택할 수 없다
- [ ] 날짜가 있는 상태에서 다시 누르면 그 날짜가 선택된 채로 달력이 열린다
- [ ] 달력의 `지우기`를 누르면 마감일이 비워진다
- [ ] 저장하면 목록 맨 위에 나타나고 "저장했습니다" Toast
- [ ] 목록에 마감일이 `마감 2026-12-01`처럼 표시된다 (없으면 안 보임)
- [ ] 추가 화면에서 `<`이나 뒤로가기를 누르면 아무것도 추가되지 않는다
- [ ] 앱을 완전히 종료했다가 다시 켜도 목록이 남아 있다

### 상태 변경 · 완료 표시 (F1.4, F1.6, 추가 기능)
- [ ] 할 일의 `시작 ▶` → 제목 앞에 `[진행 중]`, 버튼이 `완료 ▶`로 바뀐다
- [ ] `완료 ▶` → 제목 취소선 + 흐리게, 이동 버튼이 사라진다
- [ ] 길게 누르기 → `상태 변경` → 완료 항목을 할 일로 되돌릴 수 있다
- [ ] 필터 버튼의 개수가 상태 변경에 맞춰 바뀐다

### 수정 (F1.4)
- [ ] 항목을 누르면 편집 화면에 기존 제목·메모·마감일·상태가 채워져 있다
- [ ] 내용과 상태를 바꾸고 저장하면 목록에 반영되고 "수정했습니다" Toast
- [ ] 편집 화면에서 `<`이나 뒤로가기를 누르면 변경되지 않는다
- [ ] 편집 중에 화면을 회전해도 입력 중인 내용이 유지된다

### 삭제 (F1.5, 추가 기능)
- [ ] 길게 누르기 → `삭제` → 확인 창에서 취소하면 그대로, 삭제하면 사라지고 "삭제했습니다" Toast
- [ ] 편집 화면의 `삭제`도 확인 후 삭제된다
- [ ] 확인 창의 `삭제` 글자와 삭제 버튼이 `#A6533C` 색이다
- [ ] 체크박스를 고르면 하단이 `선택 해제` · `선택 삭제 (n)`으로 바뀌고 n이 맞다
- [ ] `선택 삭제` → 확인 → 고른 항목만 사라지고 "n개 삭제했습니다" Toast
- [ ] `선택 해제`나 뒤로가기를 누르면 선택이 풀리고 `+ 추가`가 다시 보인다
- [ ] 선택한 상태에서 필터를 바꾸면 선택이 초기화된다

### 필터 (추가 기능)
- [ ] 필터 버튼을 누르면 해당 상태만 보이고, 괄호 안 개수가 맞다
- [ ] "진행 중" 필터에서 `완료 ▶`를 누르면 그 항목이 목록에서 빠진다
- [ ] 화면을 회전해도 선택한 필터와 목록이 유지된다
