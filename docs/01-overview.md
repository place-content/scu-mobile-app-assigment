# 01. 개요

## 과제 요구사항 (교안 12~13주차)
- 단일 기기에서 할 일을 관리하는 Android 앱
- 필수 기능 F1.1~F1.6을 모두 구현
- 자기만의 기능을 1개 이상 추가 구현

| 코드 | 기능 | 교안 설명 |
|---|---|---|
| F1.1 | 할 일 조회 | 현재 저장되어 있는 할 일 목록을 화면에 표시 |
| F1.2 | 할 일 입력 | 새로운 할 일을 생성하고 사용자 입력을 처리 |
| F1.3 | 할 일 저장 | 할 일을 데이터베이스에 저장 |
| F1.4 | 할 일 수정 | 사용자 입력에 따라 데이터베이스에 저장된 데이터 갱신 |
| F1.5 | 할 일 삭제 | 데이터베이스에서 데이터 삭제 |
| F1.6 | 완료 여부 표시 | 할 일 완료 여부에 따라 할 일 목록에서 다른 스타일 적용 |

(심화 선택 F2.x — 여러 기기 공유는 구현하지 않음)

## 앱 소개
| 항목 | 내용 |
|---|---|
| 앱 이름 | 할 일 관리 |
| 패키지 | `com.k0h5.todolist` |
| 언어 | Kotlin |
| UI | XML 레이아웃 + ViewBinding |
| 구조 | MVVM (교안 구조 그대로) |
| 저장소 | Room (기기 내부 SQLite) |
| 최소/타깃 SDK | 24 / 37 |

## 필수 기능 구현 요약
| 코드 | 이 앱에서는 |
|---|---|
| F1.1 | 목록 화면이 DB를 구독하고 있어서, 데이터가 바뀌면 목록이 자동으로 다시 그려짐 |
| F1.2 | 추가 화면에서 제목(필수)·메모·마감일 입력. 마감일은 달력으로 고름 |
| F1.3 | 저장 버튼 → Room DB에 insert → "저장했습니다" Toast |
| F1.4 | 항목을 누르면 편집 화면. 기존 값이 채워져 있고, 저장하면 update → "수정했습니다" Toast |
| F1.5 | 3가지 방법(길게 누르기 메뉴, 편집 화면 삭제 버튼, 체크박스 선택 일괄 삭제). 모두 확인 창을 거침 |
| F1.6 | 완료: 제목 취소선 + 흐리게 / 진행 중: 제목 앞 `[진행 중]` / 할 일: 기본 |

## 추가 기능 (자기만의 기능)
| 기능 | 설명 |
|---|---|
| 상태 3단계 | 완료/미완료 대신 **할 일 → 진행 중 → 완료** 세 단계로 관리 |
| 상태별 필터 | 목록 위 `전체 / 할 일 / 진행 중 / 완료` 버튼. 각 버튼에 개수 표시 |
| 이동 버튼 | 항목 오른쪽 `시작 ▶` / `완료 ▶` 한 번 탭으로 다음 단계로 이동 (Jira 보드에서 카드를 옆 칸으로 옮기는 느낌) |
| 체크박스 일괄 삭제 | 체크박스로 여러 개 고른 뒤 `선택 삭제 (n)`으로 한 번에 삭제 |
| 마감일 달력 | 마감일 칸을 누르면 달력(DatePicker). 오늘 이전 날짜는 고를 수 없음 |
| 피드백 Toast | 저장·수정·삭제 결과와 입력 오류를 Toast로 알림 |

## 교안과 달라진 점
| 교안 | 이 앱 | 이유 |
|---|---|---|
| `done: Boolean` (완료/미완료) | `status: TodoStatus` (3단계) | "시작은 했지만 안 끝난 일"을 구분하려고 |
| 체크박스 = 완료/해제 | 체크박스 = 삭제할 항목 선택 | 완료는 이동 버튼으로 처리하고, 여러 개를 한 번에 지울 수단이 필요해서 |
| 길게 누르기 메뉴 `완료/해제, 수정, 삭제` | `상태 변경, 수정, 삭제` | 상태가 3개라 "완료/해제"로는 부족해서 |
| 제목만 수정 (`updateTitle`) | 제목·메모·마감일·상태 모두 수정 | 편집 화면의 모든 입력칸이 실제로 저장되게 |
| 우선순위 Spinner | 없음 | 상태 3단계가 비슷한 역할을 해서 화면을 단순하게 유지 |
| 마감일 직접 입력(YYYY-MM-DD) | 달력에서 선택, 과거 날짜 금지 | 잘못된 날짜 입력을 원천 차단 |
| 취소 버튼 | 상단 `<` 뒤로 버튼 | 화면이 깔끔하고, 안드로이드 앱에서 흔한 방식 |

자세한 이유는 [08-decisions.md](08-decisions.md) 참고.
