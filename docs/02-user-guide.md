# 02. 사용 가이드

앱은 화면 3개로 되어 있습니다. (Android에서는 화면 하나를 **Activity**라고 부르는데, Next.js의 `page.tsx` 하나라고 생각하면 됩니다.)

| 화면 | 클래스 | 레이아웃 파일 |
|---|---|---|
| ① 목록 | `TodoListActivity` | `activity_todo_list.xml`, `item_todo.xml` |
| ② 추가 | `AddTodoActivity` | `activity_add_todo.xml` |
| ③ 편집 | `EditTodoActivity` | `activity_edit_todo.xml` |

---

## ① 목록 화면 (앱을 켜면 처음 보이는 화면)

```
할 일 목록
(●전체 (4)) (○할 일 (2)) (○진행 중 (1)) (○완료 (1))
┌──────────────────────────────────────────┐
│ ☐ 장보기                 마감 2026-12-01  시작 ▶ │
│   우유, 계란                                │
│ ☐ [진행 중] 과제 보고서    마감 2026-11-20  완료 ▶ │
│ ☐ 운동                                   시작 ▶ │
│ ☐ 청소 (취소선, 흐리게)                          │
└──────────────────────────────────────────┘
[                 + 추가                 ]
```
> 📷 스크린샷: 목록 화면

### 구성 요소
| 요소 | ID | 설명 |
|---|---|---|
| 필터 버튼 | `rgFilter` (`rbAll`, `rbTodo`, `rbInProgress`, `rbDone`) | 누른 상태의 할 일만 보여줌. 괄호 안은 개수 |
| 목록 | `rvTodos` | 할 일 목록. 최근에 추가한 것이 위 |
| 빈 목록 안내 | `tvEmpty` | 보여줄 할 일이 없으면 "할 일이 없습니다" |
| 추가 버튼 | `btnAddTodo` | ② 추가 화면으로 이동 |
| 선택 해제 | `btnClearSelection` | 체크박스를 하나 이상 골랐을 때만 보임 |
| 선택 삭제 | `btnDeleteSelected` | 체크박스를 하나 이상 골랐을 때만 보임. `선택 삭제 (n)` |

### 목록 한 줄 (`item_todo.xml`)
| 요소 | ID | 설명 |
|---|---|---|
| 체크박스 | `cbSelect` | 삭제할 항목 선택 (완료 처리가 아님!) |
| 제목 | `tvItemTitle` | 진행 중이면 앞에 `[진행 중]`, 완료면 취소선 + 흐리게 |
| 메모 | `tvNote` | 메모가 없으면 숨김 |
| 마감일 | `tvDueDate` | `마감 2026-12-01`. 마감일이 없으면 숨김 |
| 이동 버튼 | `btnMove` | 할 일: `시작 ▶`, 진행 중: `완료 ▶`, 완료: 버튼 없음 |

### 동작
| 하고 싶은 것 | 방법 |
|---|---|
| 할 일 추가 | `+ 추가` |
| 할 일 → 진행 중 | `시작 ▶` |
| 진행 중 → 완료 | `완료 ▶` |
| 아무 상태로나 바꾸기 (완료 → 할 일 포함) | 항목 길게 누르기 → `상태 변경` → 선택 |
| 수정 | 항목 누르기, 또는 길게 누르기 → `수정` |
| 하나 삭제 | 길게 누르기 → `삭제` → 확인 창에서 `삭제` |
| 여러 개 삭제 | 체크박스로 선택 → `선택 삭제 (n)` → 확인 창에서 `삭제` |
| 선택 취소 | `선택 해제` 또는 기기 뒤로가기 |
| 상태별로 보기 | 상단 필터 버튼 |

참고
- 필터를 바꾸면 체크박스 선택이 초기화됩니다. (안 보이는 항목이 같이 삭제되는 것을 막기 위함)
- "진행 중" 필터에서 `완료 ▶`를 누르면 그 항목은 목록에서 바로 빠집니다. (완료로 바뀌었으니까)

## ② 추가 화면

```
┌──────────────────────────┐
│ <  할 일 추가              │
├──────────────────────────┤
│ 제목을 입력하세요           │
│ 메모를 입력하세요 (선택)     │
│                          │
│ 눌러서 날짜 선택 (선택)      │
│ [          저장         ] │
└──────────────────────────┘
```
> 📷 스크린샷: 추가 화면 / 달력

| 요소 | ID | 설명 |
|---|---|---|
| 뒤로 | `toolbar`의 `<` | 저장하지 않고 목록으로 (= 취소). 기기 뒤로가기도 같음 |
| 제목 | `etTitle` | 필수. 비우고 저장하면 "제목을 입력하세요" Toast |
| 메모 | `etNote` | 선택. 여러 줄 |
| 마감일 | `etDue` | 선택. 누르면 달력. 오늘 이전은 선택 불가. 달력의 `지우기`로 비우기 |
| 저장 | `btnSave` | 검증 통과 시 목록으로 돌아가고 "저장했습니다" Toast |

## ③ 편집 화면

```
┌──────────────────────────┐
│ <  할 일 편집              │
├──────────────────────────┤
│ 제목    [과제 보고서      ] │
│ 메모    [               ] │
│ 마감일  [2026-11-20     ] │
│ 상태    [진행 중        ▾] │
│ [  삭제  ]  [   저장   ]   │
└──────────────────────────┘
```
> 📷 스크린샷: 편집 화면

| 요소 | ID | 설명 |
|---|---|---|
| 뒤로 | `toolbar`의 `<` | 변경 사항 버리고 목록으로 |
| 제목/메모/마감일 | `etTitle`, `etNote`, `etDue` | 기존 값이 채워진 채로 열림 |
| 상태 | `spStatus` | 할 일 / 진행 중 / 완료 중 선택 (Spinner = HTML `<select>`) |
| 삭제 | `btnDelete` | 확인 창 → 삭제 후 목록으로, "삭제했습니다" Toast |
| 저장 | `btnSave` | 검증 통과 시 목록으로, "수정했습니다" Toast |

마감일 규칙: 기본은 오늘부터 선택 가능. 단, 이 할 일의 원래 마감일이 이미 지났다면 그 날짜까지는 그대로 둘 수 있음 (제목만 고치려는데 마감일 때문에 저장이 막히지 않도록).

## 알림 문구 모음 (`strings.xml`)
| 상황 | 문구 |
|---|---|
| 추가 저장 | 저장했습니다 |
| 수정 저장 | 수정했습니다 |
| 하나 삭제 | 삭제했습니다 |
| 여러 개 삭제 | n개 삭제했습니다 |
| 삭제 확인 | 이 할 일을 삭제할까요? / 선택한 n개를 삭제할까요? |
| 제목 없음 | 제목을 입력하세요 |
| 과거 마감일 | 마감일은 오늘부터 선택할 수 있습니다 |
| 편집할 항목이 없음 | 할 일을 찾을 수 없습니다 |
